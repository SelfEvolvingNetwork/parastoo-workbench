# سندباکس عامل پرستو روی سرور (mohsen) — نصب‌شده از مخزن کارگاه

این مسیر محل دائمی آزمایش‌های عامل است، به فرمان مالک (۲۰۲۶-۱۱-۱۰):
«بخشی را در سرور من به‌عنوان سندباکس درست کن و آزمایش‌های خودت را همیشه آنجا انجام بده.»

نسخهٔ رسمی اسکریپت‌ها و قرارداد کامل: `https://github.com/SelfEvolvingNetwork/parastoo-workbench`
این فایل نسخهٔ نصب‌شده است — برای تغییر، آن مخزن را به‌روز کن و دوباره bootstrap بزن.

## قواعد

1. **بیرون از درخت نصب است** (`/opt/parastoo` دست‌نخورده می‌ماند) — آپدیت خودکار و استقرار هرگز اینجا را پاک نمی‌کنند.
2. **آزمایش‌های سنگین همیشه اینجا** اجرا می‌شوند نه در سندباکس محلی عامل: سوئیت‌های اسموک روی درخت کاری، راستی‌آزمایی، آزمایش دستی API، خروجی موقت.
3. **رازها اینجا نوشته نمی‌شوند** — نه توکن، نه رمز، نه `.env`؛ احراز فقط در لایهٔ پل access-agent است.
4. **منابع:** دیسکِ `tmp/` خودپاک است؛ سرور ۴GB رم دارد — هرگز هم‌زمان با استقرار کار سنگین اجرا نشود.
5. درخت کاری آزمایش در `tmp/gate-*/` ساخته و پس از هر دروازه پاک می‌شود.

## چیدمان

| مسیر | نقش |
| --- | --- |
| `workbench/` | کلون مخزن کارگاه (منبع اسکریپت‌ها؛ ارتقا: `git pull` + `bootstrap.sh`) |
| `parastoo/` | کلون کامل مخزن پرستو — منبع درخت‌های کاری دروازه |
| `tmp/` | خط‌خطی‌های زودگذر — `cleanup.sh` هرچه >۷ روز باشد حذف می‌کند |
| `results/` | سند نتایج: `gate-history.log` (هر دروازه یک ردیف) |
| `logs/` | لاگ عملیات (دروازه، bootstrap) |
| `tools/bin/` | ابزارهای تک‌فایلی نصب‌شده از ریلیز گیت‌هاب (ruff) |
| `venv/` | باقی‌ماندهٔ تلاش pip — منسوخ؛ قابل حذف |

## کاربرد

```bash
bash /opt/parastoo-sandbox/gate.sh /opt/parastoo-sandbox/tmp/gate-<sha>   # دروازهٔ سبز
bash /opt/parastoo-sandbox/cleanup.sh                                      # پاک‌سازی
python3 /opt/parastoo-sandbox/workbench/server/selfcheck.py --human        # خودآزمایی
```

## درس‌های محیط (تجربهٔ ثابت‌شده ۱۴۰۵/۰۸)

- **DNS خروجی بسته به‌جز گیت‌هاب** — pip سودمند نیست؛ ابزار از ریلیز گیت‌هاب می‌آید؛ اسموک داخل ایمیج `parastoo/core:latest` با `--network none`.
- پل exec هر فرمان را ۶۰ ثانیه می‌کشد — کارِ طولانی: `nohup … &` + پولینگ.
- در `pkill` الگوی خود-تطبیقی: `pkill -f 'pat[t]'`.
